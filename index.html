🚀 How to Deploy Any of These Sites

Because each subfolder contains pure HTML, CSS, and JavaScript, they are 100% static, fast, and ready to deploy anywhere without build steps or complex configurations.

OPTION 1

Vercel / Netlify

Drag and drop any subfolder directly onto Netlify Drop or import to Vercel with Root Directory set to nexus-ai, aura-home, or pulsefit-coaching.

OPTION 2

GitHub Pages

Push the repository to GitHub, go to Settings > Pages, and serve either the root directory (hub) or a specific branch.

OPTION 3

Cloudflare Pages

Connect your Git repo on Cloudflare Pages and deploy instantaneously with global CDN and SSL encryption.
